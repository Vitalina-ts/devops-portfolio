# DevOps Portfolio

## Про мене

Мене звати Віталіна Цикаляк. Я студентка та початківиця у DevOps, яка вивчає професійні підходи до налаштування середовища розробки, контролю версій, контейнеризації й автоматизації.

Цей репозиторій містить мої лабораторні роботи, практичні завдання та фінальний проєкт із курсу DevOps.

## Професійна мета

Моя мета — отримати практичні навички DevOps, навчитися працювати з Linux, контейнерами, CI/CD та хмарною інфраструктурою й підготуватися до першого стажування або Junior DevOps позиції.

### Перший квартал

* закріпити Git, GitHub і роботу з гілками;
* вивчити основи Linux та Bash;
* краще зрозуміти мережі й роботу SSH.

### Другий квартал

* поглибити знання Docker і Docker Compose;
* навчитися створювати CI/CD-процеси через GitHub Actions;
* практикувати автоматичні перевірки та розгортання.

* вивчити основи Kubernetes;
* почати працювати з Terraform;
* познайомитися з хмарною інфраструктурою.

### Четвертий квартал

* вивчити базовий моніторинг і логування;
* створити завершений DevOps-проєкт;
* підготувати портфоліо до пошуку стажування або першої роботи.
